# Calculadora Avançada em C#

## 📚 Sobre o Projeto
Este é um projeto de portfólio que demonstra minhas habilidades em **C#** e desenvolvimento de interface gráfica de usuário (**GUI**) com **Windows Forms**. A aplicação é uma calculadora multifuncional que vai além das operações básicas, oferecendo uma variedade de funções matemáticas e utilitárias em uma interface limpa e intuitiva.

## ✨ Funcionalidades Principais
* **Operações Aritméticas:** Soma, subtração, multiplicação, divisão e divisão com resto.
* **Funções Trigonométricas:** Seno, Cosseno e Tangente.
* **Cálculos Avançados:** Raiz Quadrada, Potenciação e sequência de Fibonacci.
* **Áreas Geométricas:** Cálculo de área de Quadrado, Retângulo e Círculo.
* **Conversor de Temperaturas:** Conversão entre Celsius, Fahrenheit e Kelvin.
* **Índice de Massa Corporal (IMC):** Ferramenta para calcular o IMC.
* **Histórico de Operações:** Acompanhe todas as suas contas em uma lista, com a opção de limpar o histórico.
* **Interface Amigável:** Design limpo e organizado para uma experiência de usuário agradável.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** C#
* **Plataforma:** .NET Framework
* **Interface Gráfica:** Windows Forms
